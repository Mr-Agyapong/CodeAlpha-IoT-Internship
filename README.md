# CodeAlpha IoT Internship

This repository contains the IoT projects I completed during my CodeAlpha IoT Internship.

## Tasks

### Task 1 - RFID Smart Access System

An RFID-based access control system using:
- Arduino Uno
- RC522 RFID reader
- 16x2 I2C LCD
- Red and green LEDs
- Buzzer
- SG90 servo motor

The system reads an RFID card/tag and provides access feedback using the LEDs, buzzer, LCD and servo.

### Task 2 - LDR Automatic Light System

An automatic lighting system using:
- Arduino Uno
- LDR/photoresistor
- 10kΩ resistor
- LED

The system monitors the surrounding light level and automatically turns the LED on when the environment becomes dark.
